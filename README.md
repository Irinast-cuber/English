# FluentPath

Personal English-learning web app for an A0/A1 → B1 study path.

## Run
Open `index.html` in a modern browser.

For best results (especially speech recognition), publish it through GitHub Pages or run it with a local web server.

## GitHub Pages
Upload all files and folders to a GitHub repository, then enable Pages from the repository settings.

## Included
- A0, A1, A2 and B1 roadmap
- sequential lesson unlocking and checkpoints
- interactive quizzes
- Error Bank
- vocabulary review with simple spaced repetition
- browser text-to-speech listening
- browser speech-recognition speaking where supported
- writing prompts
- daily mixed challenge
- XP, streak and skill statistics
- daily checklist with reversible checkmarks
- localStorage progress
- responsive mobile layout

Note: This is a personal study tool, not an official CEFR certification test.
